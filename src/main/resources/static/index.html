DocFlow is a secure REST API for organizing projects, issuing API keys, and managing asynchronous document-processing jobs.

API entry points

Authenticate first, then use the returned bearer token for protected resources.

POST  /api/auth/registerPublic
POST  /api/auth/loginPublic
GET   /api/projectsJWT
GET   /api/projects/{id}/jobsJWT

Built for production workflows

Core infrastructure is connected and ready for API clients.

JWT securityStateless authentication and protected tenant resources.
PostgreSQLPersistent project, key, job, and attempt records.
Job lifecycleQueued, running, retry, success, and failure states.
IdempotencyDuplicate job submissions are safely controlled.
